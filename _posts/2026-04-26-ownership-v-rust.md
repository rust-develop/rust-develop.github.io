В [прошлой статье](/2026/04/26/chto-takoe-rust/) мы познакомились с Rust и его основными принципами. Сегодня разберём одну из самых важных и уникальных концепций языка — **систему владения (Ownership)**.

## Зачем нужна система владения?

В большинстве языков программирования управление памятью решается одним из двух способов:

- **Сборщик мусора** (Java, Go, Python) — автоматически освобождает память, но создаёт накладные расходы в рантайме
- **Ручное управление** (C, C++) — максимальная производительность, но высокий риск ошибок: утечки памяти, двойное освобождение, use-after-free

Rust выбрал третий путь: **система владения**, проверяемая компилятором во время компиляции. Никакого сборщика мусора, никаких ошибок памяти в рантайме.

## Три правила владения

Вся система строится на трёх простых правилах:

1. Каждое значение в Rust имеет **единственного владельца**
2. В любой момент времени может существовать только **один владелец**
3. Когда владелец выходит из области видимости — значение **автоматически уничтожается**

## Перемещение (Move)

Когда вы присваиваете значение другой переменной, происходит **перемещение** (move) — старый владелец теряет право на значение:

```rust
fn main() {
    let s1 = String::from("Привет");
    let s2 = s1; // s1 перемещается в s2

    // println!("{}", s1); // Ошибка компиляции! s1 больше не действителен
    println!("{}", s2); // OK
}
```

Это не копирование — это передача права собственности. Компилятор гарантирует, что никто не обратится к уже перемещённому значению.

> **Примечание:** Примитивные типы (числа, bool, char) реализуют трейт `Copy` и копируются автоматически, без перемещения.

## Клонирование (Clone)

Если вам нужна именно копия данных — используйте метод `.clone()`:

```rust
fn main() {
    let s1 = String::from("Привет");
    let s2 = s1.clone(); // Глубокое копирование

    println!("s1 = {}, s2 = {}", s1, s2); // Оба действительны
}
```

Клонирование явно показывает, что происходит копирование данных — это дорогая операция, которую не стоит делать без необходимости.

## Владение и функции

Передача значения в функцию работает так же, как и присвоение:

```rust
fn takes_ownership(s: String) {
    println!("{}", s);
} // s уничтожается здесь

fn makes_copy(x: i32) {
    println!("{}", x);
} // x — примитив, просто копируется

fn main() {
    let s = String::from("Rust");
    takes_ownership(s); // s перемещается в функцию

    // println!("{}", s); // Ошибка! s уже перемещён

    let x = 5;
    makes_copy(x); // x копируется
    println!("{}", x); // OK, x всё ещё доступен
}
```

## Возврат значений

Функция может вернуть владение обратно:

```rust
fn gives_ownership() -> String {
    let s = String::from("Владею этим");
    s // возвращаем владение вызывающему коду
}

fn takes_and_gives_back(s: String) -> String {
    s // получаем и сразу возвращаем владение
}

fn main() {
    let s1 = gives_ownership();
    let s2 = String::from("привет");
    let s3 = takes_and_gives_back(s2);

    println!("{}, {}", s1, s3);
}
```

Но постоянно передавать и возвращать владение — неудобно. Для этого в Rust есть **заимствование (borrowing)**, которое мы разберём в следующей статье.

## Область видимости и Drop

Когда переменная выходит из области видимости, Rust автоматически вызывает функцию `drop()`, освобождающую память:

```rust
fn main() {
    {
        let s = String::from("внутри блока");
        println!("{}", s);
    } // Здесь вызывается drop(s) — память освобождается

    // println!("{}", s); // Ошибка! s вне области видимости
}
```

Это детерминированное освобождение памяти: вы точно знаете, когда и где она освободится.

## Итоги

Система владения — это то, что делает Rust уникальным. Она может казаться сложной в начале, но именно благодаря ей Rust гарантирует безопасность памяти без сборщика мусора.

Ключевые моменты:
- **Move** — передача права владения, старый владелец становится недействителен
- **Copy** — автоматическое копирование примитивных типов
- **Clone** — явное глубокое копирование
- **Drop** — автоматическое освобождение памяти при выходе из области видимости

В следующей статье разберём **заимствование (borrowing)** и **ссылки** — механизм, который позволяет использовать данные без передачи владения. Следите за обновлениями!
